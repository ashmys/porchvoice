Chat history

Clear conversation?

This empties the conversation panel, erases this conversation's saved messages (this room's chat log file) and resets the model's memory of the conversation. This cannot be undone.

Restart everything?

The LiveKit server and the agent worker will stop and start again with your saved settings. This takes a few seconds (models reload). Any ongoing call ends.
